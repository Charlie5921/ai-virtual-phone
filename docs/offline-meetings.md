# 角色代发与线下场次

聊天 ➕ 第二页的「替 TA 发言」将手动文字保存为角色消息，不请求模型；可使用原有消息编辑和删除操作。

线下顶部「场次 / 结束」可为当前场次命名，结束并总结。切回线上只是暂停；已结束的正文保留在过往线下，新场次不会包含旧场次的正文历史。旧记录无 meetingId，仍视为当前场次。

总结使用记忆总结 API，未配置时使用角色聊天 API。长场次分块整理，会有多次 API 调用。失败后记录仍归档，可补总结或手工填写总结。总结写入原有长期记忆库；正常记忆开关与召回预算仍生效，不保证每次请求携带所有记忆。

场次由原有轮次的 meetingId 与注册 KV 前缀 ai_phone_offline_meetings: 关联，纳入通用备份。总结使用稳定记忆 ID，重试/修改覆盖同一条记忆。清空线下记录会清理场次目录，已写入的长期记忆按原有规则保留。

参考 wanonewan/wanwan 的场次结束、失败可补总结交互思路，代码为本项目独立实现。

验证：node tests/offline-meetings.cjs；npx tsc --noEmit；npm run build。
