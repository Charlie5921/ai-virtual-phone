# 聊天个性化与反查手机

## 我的潜台词

长按自己发出的消息，选择「输入潜台词」。保存后在气泡中折叠显示「我的潜台词」；长按可编辑，清空并保存可移除。

潜台词保存在消息的独立字段中，不改正文。单聊和群聊组装上下文时，把它作为未说出口的场外提示附在原消息后，不让角色直接读心。保存不会自动重生成已有回复；删除或撤回消息后，不再使用这段提示。只有该消息仍在当前提示词的历史范围内，潜台词才会随它注入。

## 用户面具

一对一聊天 → 更多 → 我的面具。

下拉列表来自手机设置中的用户身份。这一入口写入该角色的 chat 用户身份绑定，不覆盖 API、预设、声音、世界书或其他应用绑定。「跟随原有绑定」清除这一层的身份覆盖。

## 角色生图长相

一对一聊天 → 更多 → 角色生图长相。

保存发型、瞳色、体型、配饰等提示词；NovelAI 推荐英文标签。实际生图会把它和当次画面描述、当前生图预设组合，OpenAI 兼容与 NovelAI 均支持。该角色的聊天、朋友圈等生图共用；不会改聊天人设，也不会自动重新生成旧图。参考图沿用原设置。清空保存恢复默认行为。

## 让 TA 查我的手机

一对一聊天 → 更多 → 让 TA 查我的手机。

先选择开放的聊天窗口，最多 6 个；每个窗口使用最近 8 条可见消息。朋友圈、虚拟钱包另行勾选。不会提供未勾选的应用、撤回消息、潜台词、角色心声或工具内部记录。

开始时，用当前角色绑定的聊天 API 调用一次生成浏览顺序、心声和反应。只会读取用户开放的小手机内容，不连接真实手机系统。模型不能添加未开放的页面，界面展示的记录摘录来自本地数据。

支持逐页、自动播放、暂停、收起旁观、拿回手机。已看的页面会保存；结束后把这些页面对应的心声和反应写入当前聊天，方便角色在后续对话接续。每个聊天保留最近 10 次记录，可清空。此版本不代发消息、拉黑联系人或修改钱包，不在后台自动发起查阅。
