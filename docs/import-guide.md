# 世界书与酒馆角色卡导入

世界书：设置 → 世界书 → 导入，支持 JSON、TXT、DOCX（不支持旧版 DOC），文件上限 20 MB。

- TXT 支持 UTF-8、带 BOM 的 UTF-16，以及常见中文 GB 编码。
- TXT 使用 `# 标题` 或独占一行的 `【标题】` 分条；没有标题时按空行分段。
- DOCX 使用 Word 内置标题 1～6 分条；无标题时按段落分条。只提取文字，不导入图片和排版。
- 文本文档没有关键词信息，导入条目默认常驻，可在世界书详情逐条修改关键词与开关。

角色档案：导入角色卡 → 选择样式 → 选择 PNG 或 JSON → 点击画布放置角色。

支持酒馆 V1、V2、V3 JSON，以及携带 `chara` / `ccv3` 文本块的 PNG。普通截图或重新压缩后丢失元数据的 PNG 无法作为角色卡导入。

放置角色后，内嵌 `character_book` 自动成为 float 世界书，保持原始条目划分，并绑定给该角色。映射关键词、标题、正文、启用状态、常驻状态、顺序、位置、深度、概率和角色。高级酒馆扩展保存在原始数据中，但不代表 float 的触发引擎支持全部酒馆行为。开场白、场景、示例对话等原始卡片字段会保留，不会因这些字段存在而拒绝导入；本次不改变聊天开场白机制。

导入创建新角色和世界书，不覆盖已有同名资料。
